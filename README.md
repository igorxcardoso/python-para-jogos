# Python para Jogos

Uma coletânea de exemplos e exercícios em Python focada no desenvolvimento de jogos simples com Pygame. O objetivo do repositório é ensinar conceitos básicos de programação para jogos (janela, entrada, desenho, lógica de jogo) através de exemplos práticos e comentados.

## O que tem aqui

- Exemplos de janelas e interação com botões
- Implementações de jogos simples (ex.: Jogo da Velha)
- Módulos utilitários e pequenos tutoriais para iniciantes

## Recursos principais

- Código em Python compatível com Python 3.7+
- Uso de Pygame para criação de janelas, sprites e entrada do usuário

## 🛠️ Requisitos

- Python 3.7 ou superior
- Pygame 2.0 ou superior
- Editor de texto ou IDE (ex.: VS Code, PyCharm)

## Instalação rápida

1. Crie e ative um ambiente virtual (recomendado):

	- Windows (PowerShell):

	```powershell
	python -m venv .venv
	.\.venv\Scripts\Activate.ps1
	```

	- Windows (cmd.exe):

	```cmd
	python -m venv .venv
	.venv\\Scripts\\activate
	```

2. Instale dependências:

```bash
pip install pygame
```

## Como executar um exemplo

1. Navegue até a pasta do exemplo desejado, por exemplo `exemplos/python-para-jogos`.
2. Execute o arquivo Python correspondente, por exemplo:

```bash
python exemplos/python-para-jogos/minha-janela.py
```

Substitua pelo nome do arquivo que quer testar (ex.: `botoes.py`, `placar.py`).

## Estrutura do repositório (resumo)

- `exemplos/` — exemplos passo a passo e scripts de demonstração
- `jogos/` — projetos de jogos (ex.: `jogo-da-velha`)
- `modulos/` — módulos e utilitários usados nos exemplos
- `imagens/` — ativos gráficos usados nos exemplos
